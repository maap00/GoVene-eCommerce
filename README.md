# GoVene 🇻🇪

### Todo lo que buscas. En un solo lugar.

GoVene es una propuesta de marketplace multisectorial diseñada para reunir productos de distintas categorías en una experiencia de compra moderna, intuitiva y visualmente atractiva.

El proyecto busca ofrecer una experiencia de comercio electrónico adaptada al mercado venezolano, combinando una interfaz premium, navegación intuitiva y métodos de pago locales representados en un flujo de compra simulado.

**GoVene es una demostración frontend desarrollada con fines de presentación, portfolio y promoción comercial. No es una plataforma de comercio electrónico en producción.**

---

## ✨ Características principales

- **Marketplace multisectorial:** catálogo organizado por categorías.
- **Diseño premium:** interfaz minimalista, moderna y responsive.
- **Catálogo de productos:** visualización de productos, precios, imágenes y detalles.
- **Búsqueda y navegación:** acceso intuitivo a productos y categorías.
- **Carrito de compras:** gestión visual de productos seleccionados.
- **Checkout:** recorrido de compra simulado.
- **Métodos de pago venezolanos:** representación visual de Pago Móvil, Zelle, Binance Pay, Cashea, Ubii, transferencias y tarjetas.
- **Moneda USD/VES:** presentación de precios en dólares y bolívares mediante datos de demostración.
- **Paneles de administración:** interfaces de demostración para la gestión de pedidos y productos.
- **Dashboard comercial:** métricas, gráficos y datos de ventas ficticios.
- **Animaciones e interacciones:** transiciones y efectos visuales diseñados para mejorar la experiencia de usuario.

## 🧰 Tecnologías

El proyecto utiliza las siguientes tecnologías frontend:

- **React** — construcción de interfaces mediante componentes.
- **Vite** — servidor de desarrollo y herramienta de compilación.
- **TypeScript** — tipado estático.
- **Tailwind CSS** — estilos y diseño responsive.
- **Framer Motion** — animaciones y transiciones.
- **Zustand** — gestión del estado de la interfaz.
- **Lucide React** — iconografía.

## 🚀 Instalación y ejecución

### Requisitos previos

- Node.js compatible con las dependencias del proyecto.
- npm.

### 1. Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
cd <CARPETA_DEL_PROYECTO>
```

### 2. Instalar dependencias

```bash
npm install
```

### 3. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir la aplicación en el navegador.

### 4. Compilar para producción

```bash
npm run build
```

### 5. Previsualizar la compilación

```bash
npm run preview
```

## 🏗️ Arquitectura y alcance

GoVene está concebido como una demostración frontend. La experiencia se construye mediante componentes reutilizables, datos de prueba y estado local.

El alcance de esta versión incluye:

- Interfaces de catálogo y detalle de productos.
- Componentes de navegación y experiencia de compra.
- Representación visual de métodos de pago.
- Interfaces administrativas y paneles de métricas.
- Interacciones simuladas para demostrar los principales recorridos del usuario.

La estructura concreta de carpetas y los scripts disponibles dependen de la implementación actual del repositorio.
